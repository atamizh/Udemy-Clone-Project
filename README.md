# Udemy-Clone-Project
The Udemy Clone is a full-stack online learning platform inspired by Udemy. It allows users to explore courses, view course details, enroll in courses, and access educational content through an intuitive and responsive interface.

A responsive Udemy Clone website built using HTML and CSS. This project recreates the look and feel of the Udemy online learning platform with a clean, modern, and user-friendly interface.

Features
* Responsive homepage design
* Search bar for courses
* Course categories and sections
* Course cards with images, titles, ratings, and pricing
* Instructor and learning sections
* Responsive layout for different screen sizes
* Styled entirely using HTML and CSS

Technologies Used
* HTML5 – For structuring the web pages
* CSS3 – For styling, layouts, colors, and responsiveness

Project Purpose
* This project was created to practice and improve my HTML and CSS skills by recreating the design and layout of a popular online    learning platform.
